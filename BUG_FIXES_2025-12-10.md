## Bug #1: LucideIcon Import Error

**Error:**
```
SyntaxError: The requested module '/node_modules/.vite/deps/lucide-react.js?v=4e3906e8'
does not provide an export named 'LucideIcon' (at ActionsDropdown.tsx:2:26)
```

**Root Cause:**
`LucideIcon` type doesn't exist in the `lucide-react` package. It was being imported as a named export but doesn't actually exist.

**File:** `src/components/shared/ActionsDropdown.tsx`

**Fix Applied:**

```diff
- import { MoreHorizontal, LucideIcon } from 'lucide-react';
+ import { MoreHorizontal } from 'lucide-react';

+ // Type for lucide-react icon components
+ type IconComponent = React.ComponentType<React.SVGProps<SVGSVGElement>>;

  export interface ActionItem {
    label: string;
-   icon: LucideIcon;
+   icon: IconComponent;
    onClick: () => void;
    // ...
  }
```

**Status:** ✅ FIXED

## Bug #2: Missing Exports in Shared Components Index

**Error:**
```
SyntaxError: The requested module '/src/components/shared/index.ts'
does not provide an export named 'PageHeader' (at desktop.tsx:66:10)
```

**Root Cause:**
During Phase 2 refactoring (component extraction), only 3 components were exported from `src/components/shared/index.ts`, but many files were still importing other components (PageHeader, StatsGrid, EmptyState, etc.) from the barrel export.

**File:** `src/components/shared/index.ts`

**Fix Applied:**

## Lessons Learned

1. **Barrel Export Management:** When creating shared component libraries, maintain comprehensive barrel exports (index.ts files). Incomplete barrel exports cause hard-to-debug import errors.

2. **Type Import Verification:** Always verify that types exist in the source package before importing. Don't assume type names based on convention.

3. **Component Library Testing:** After extracting components into a shared library, test that all exports are properly configured before considering the refactor complete.

4. **Import Pattern Consistency:** When multiple files import from a barrel export, ensure all exported components are listed in the barrel file.
